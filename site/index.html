Desktop companion · Windows · Open source

A small robot that sits on your desktop.

Pixy answers Claude Code's permission prompts from on top of every window, chats with a model running on your own machine, and goes quiet until it has something to say. Nothing leaves the disk it was written to.

Idle

01 · Claude Code

Answers Claude Code for you.

Claude Code asks before it runs a command or edits a file. Normally that prompt waits in whichever terminal you started it in. Pixy floats it on top of everything, so you can approve from wherever you are, and the answer goes straight back to Claude.

  • The real command, file path and diff are on the card
  • Several sessions waiting at once simply stack
  • Multiple-choice questions become tappable chips

02 · Local model

Chats with a model on your own machine.

Point it at whatever you run locally. Streaming replies, syntax highlighting, several named models you can switch between mid-thought. Attach documents or images; edit a message and send it again, or retry a single reply.

03 · Memory

Remembers what you already discussed.

Ask “what did we decide about caching?” and it finds the conversation that said cache, searched across everything you have ever talked about and quietly added to your new question. Add an embedding server and it also finds the one that made the same point in different words.

04 · Notices

Tells you what happened while you were working.

Unread mail with a one-line summary written by your local model. A morning brief. A nudge before a meeting. Merged pull requests, failing CI, and issues that just landed on you. All as notices that appear and go away, not another tab to check.

05 · And a few more things

Listens when you say “hey pixy”

An on-device wake word, then transcription and speech through local servers. Nothing is recorded or sent before it fires.

Keeps notes

Markdown with wiki-links, pinning and a focus mode. Real files in a real folder, editable by anything.

Plays music, draws pictures

Music controls and per-app volume. Text-to-image through a local server, started when you ask and stopped when you're done.

Using it

A pill that stays out of the way.

Clicks pass straight through to whatever is underneath unless the cursor is actually on Pixy, so it can sit on top of your editor without getting in the way.

Local by default

A straight answer, not a reassurance.

  • Your history stays home. Chat history, notes, memory and the search index never leave the machine. Remembered history isn't sent to a hosted model unless you turn that on.
  • Your own keys. You supply your own OAuth client and tokens. There is no shared application and no secret compiled into the binary.
  • Honest about storage. Secrets are stored in plaintext on your machine: a deliberate trade-off for a local-first tool, explained rather than hidden.
  • The web is hostile input. Pages a model chose to read are treated as untrusted. The full threat model is in SECURITY.md.

Get started

Three steps, none of them in a particular order.

  1. 1

    Install it

    Run the installer. Windows will warn that it's unsigned: choose More info → Run anyway.

    Installer (.exe) .msi Portable
  2. 2

    Open Settings

    From the tray icon, fill in whatever you want to use. Pixy starts fine with none of it; every feature stays quiet until it's configured.

  3. 3

    Hook up Claude Code

    Paste a few lines of hook configuration into .claude/settings.json. SETUP.md walks through it, one feature at a time.
