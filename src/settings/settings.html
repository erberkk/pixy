Mail & calendar

Connects Gmail and Google Calendar, read-only, for arriving-mail notices and the morning brief. It uses an OAuth client you create once in your own Google Cloud console — nothing is shared with, or routed through, anyone else.

OAuth client

In console.cloud.google.com: create a project, enable the Gmail API and the Google Calendar API, then under Credentials create an OAuth client ID of type Desktop app. Paste its two values below. On the consent screen, add yourself as a test user.

Mailboxes

One client, any number of mailboxes — the client above is the app's identity, not yours. Add a personal and a work account and each gets its own sign-in; notices and the morning card then say which inbox they came from.

While your consent screen is in "Testing", Google expires the sign-in after seven days and the widget will ask you to connect again. Moving it to "In production" — no review needed for your own use — avoids that.

Images

Where /image in the Chat window sends a description. A local drawing server — stable-diffusion.cpp’s sd-server is the one this was built against; it needs no account and no key. Nothing here talks to anything off this machine.

Memory

Conversations you have already had, made findable from the ones you have next. Ask about something discussed last week and the relevant part of it is quietly added to your question — typed or spoken, either one can reach the other. Nothing is added when nothing is relevant, which is most of the time.

What’s indexed

Conversation files

One JSON file per conversation. Move them somewhere you back up if you want to keep them — the files come with you. The search index stays with the app either way, since it is only a cache and is rebuilt from these files.

Advanced

Values that depend on your machine rather than on the widget — your room’s noise, your speech server’s speed, how long you have to be away before the mascot thinks you left. Every one of them has a working default, so nothing here needs touching to get started.
